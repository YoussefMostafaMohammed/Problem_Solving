## فهم الميموري والـ Data Types

البايت (**byte**) هو وحدة تخزين في الميموري.  
يعني أي مكان في الميموري نقدر نقول عليه عبارة عن **شوية بايتس**.

البايت نفسه بيتكوّن من وحدات أصغر منه اسمها **بت (bit)**،  
وكل بايت فيه **8 بت**.

كل بت بتاخد واحدة من قيمتين بس:  
يا إمّا **0** يا إمّا **1**.

---

##  النوع `int`

الـ **int** بيتكوّن من **4 بايت**،  
يعني 4×8=324 × 8 = 324×8=32 بت.
بس خد بالك 👀، أكبر رقم يشيله الـ `int` **مش 2^32 - 1**،  
لإنه بيشيل أرقام موجبة وسالبة، فبيستخدم بت واحد للإشارة.

فبيكون التوزيع كده:
- 1 بت للإشارة
- 31 بت للقيمة الفعلية

يعني:
- **أكبر رقم** يقدر يشيله الـ `int`:  
    231−1=21474836472^{31} - 1 = 2147483647231−1=2147483647 → تقريبًا **2 مليار**
- **أصغر رقم** يقدر يشيله:  
    −231=−2147483648-2^{31} = -2147483648−231=−2147483648 → تقريبًا **سالب 2 مليار**

---

##  المتغيرات (Variables) والمؤشرات (Pointers)

دلوقتي لو عندنا متغير اسمه `x` في الميموري،  
ينفع نعمل متغير تاني **يبقى باصص عليه**؟  
 أيوه، نقدر نعمل كده باستخدام **الـ pointer**.

الـ **pointer** هو متغير بيخزن **عنوان الميموري** بتاع متغير تاني.  
يعني بدل ما يشيل قيمة عادية، بيشيل مكانها في الميموري.

مثلاً:
```c++
int x = 10;
int* ptr = &x; // ptr بيشاور على x
```


كده ptr بيشاور على نفس المكان اللي فيه x.
ولو غيّرت x، القيمة اللي ptr بيشاور عليها هتتغيّر كمان.

 الدالة sizeof()
الدالة sizeof() بتقولّك المتغير دا واخد مساحة قد إيه من الميموري.
يعني بتعرفك عدد البايتات اللي النوع دا بيستخدمها.

مثلاً:
```c++
cout << sizeof(int);   // هتطبع 4
cout << sizeof(char);  // هتطبع 1
cout << sizeof(double); // هتطبع 8
```

 مفيدة جدًا لما تحب تعرف نوع البيانات بياخد مساحة قد إيه بالظبط،
خصوصًا في الأنظمة المضمنة (Embedded Systems) أو لما تشتغل على الميموري بشكل مباشر.

---
##  ليه لازم نعمل Free للميموري؟

في العادي لما بتعرّف متغير عادي زي كده:

```c++
int x = 10;
```

الميموري بتتخصّص (تتحجز) **تلقائي** في الـ **stack**،  
ولما الفانكشن اللي فيها المتغير تخلص،  
الـ compiler بيرجع يحرّر الميموري دي لوحده،  
يعني انت مش محتاج تعمل أي حاجة بنفسك.

لكن الموضوع بيختلف لما تستخدم **الميموري الديناميكية** (Dynamic Memory).  
يعني لما تخصّص ميموري بنفسك باستخدام `new` أو `malloc`.

مثلاً:

```c++
int* ptr = new int;      // تخصيص ميموري جديدة
*ptr = 100;              // استخدم الميموري
```

في الحالة دي 
الميموري دي اتخزنت في **heap** مش في stack،  
وده معناه إن **الكمبيلر مش هيمسحها لوحده**!

فلو انت خلّصت استخدام الميموري دي وممسحتهاش،  
هتفضل محجوزة جوه الرام بدون استخدام،  
وده اسمه **memory leak** (تسريب في الذاكرة).
 ومع الوقت، تسريبات الميموري دي ممكن تبوّظ البرنامج أو تخليه يهنّج.

---
## الحل: استخدم delete أو free

بعد ما تخلص استخدام الميموري اللي حجزتها بـ `new` أو `malloc`،  
لازم ترجعها للنظام باستخدام:

### لو استخدمت `new` → استخدم `delete`

```c++
delete ptr;
```

### لو استخدمت `new[]` (لمصفوفة) → استخدم `delete[]`

```c++
delete[] arr;
```
### لو استخدمت `malloc` → استخدم `free`

```c++
free(ptr);
```

----
## ملاحظات مهمة:

- متعملش `delete` أو `free` على نفس العنوان مرتين  
    (ده ممكن يبوّظ البرنامج أو يعمل crash).
- بعد ما تعمل `delete`،  
    عشان تبقى في الأمان خليك تعوّد نفسك تكتب كده:
```c++
delete ptr;
ptr = nullptr;
```
- كده انت بتتأكد إن المؤشر مش باصص على عنوان ميموري محذوف.

## الـ Array (المصفوفة)

المصفوفة هي **مجموعة من العناصر من نفس النوع** متخزنة جنب بعض في الميموري.  
يعني بدل ما يكون عندك متغير واحد، تقدر تخزن مجموعة أرقام أو قيم في مكان واحد.

### تعريف Array

```c++
int arr[5]; // مصفوفة من 5 عناصر من نوع int
```

- هنا `arr` بيكون **اسم المصفوفة**.
- `[5]` معناه ان المصفوفة فيها **5 خانات**.
- كل خانة فيها **int** يعني كل خانة بتاخد 4 بايت (على حسب sizeof(int)).

### الوصول للعناصر

ممكن توصل لأي عنصر في المصفوفة باستخدام **index** (الترقيم بيبدأ من 0):

```c++
arr[0] = 10; // أول عنصر
arr[1] = 20; // ثاني عنصر
```

### الميموري في المصفوفة
المصفوفة بتتحجز كلها **جنب بعض** في الذاكرة.  
لو عندك `int arr[5];` يبقى الميموري شكلها كده:

| العنصر  | arr[0] | arr[1] | arr[2] | arr[3] | arr[4] |
| ------- | ------ | ------ | ------ | ------ | ------ |
| العنوان | 1000   | 1004   | 1008   | 1012   | 1016   |

كل عنصر بياخد **4 بايت**، وده سبب اختلاف العناوين.

---

## المؤشر على المصفوفة (Array Pointer)

لو عندك مصفوفة، ممكن تعمّل **pointer** يشاور على أول عنصر فيها:

```c++
int* ptr = arr; // ptr بيشاور على arr[0]
```

- دلوقتي لو عملت:
    
```c++
cout << *ptr; // هتطبع arr[0]
ptr++;
cout << *ptr; // هتطبع arr[1]
```

- المؤشر بيتحرك حسب حجم النوع اللي بيشاور عليه (int هنا 4 بايت).

لو عندك مصفوفة زي كده:
```c++
int arr[5] = {10, 20, 30, 40, 50};
```
وبعد كده حاولت تعمل:

```c++
arr++; // ❌ غلط
```

### ليه ده غلط؟
- `arr` مش **pointer عادي**، ده **اسم المصفوفة**.
- اسم المصفوفة في C++ **بيمثل عنوان أول عنصر**، بس هو **ثابت**.
- لما تقول `arr++`، أنت بتحاول تغيّر العنوان اللي بيشاور عليه الاسم، وده **مش مسموح**.
باختصار
- اسم المصفوفة **مش pointer قابل للتغيير** → فلا ينفع نعمل ++ أو -- عليه.
- لكن لو عندك **pointer فعلي** يشاور على أول عنصر، ساعتها ينفع:

```c++
int* ptr = arr; // ptr بيشاور على arr[0]
ptr++;           // صح، دلوقتي بيشاور على arr[1]
```

---

### توضيح بالذاكرة

لو عندك مصفوفة:

|العنصر|arr[0]|arr[1]|arr[2]|
|---|---|---|---|
|العنوان|1000|1004|1008|

- `arr` دايمًا = 1000 (عنوان أول عنصر)
    
- `ptr = arr` بيبدأ كده كمان: ptr = 1000
    
- لما تعمل `ptr++` → ptr = 1004 (بيشاور على العنصر اللي بعده)
    

**لكن arr++** → ❌ غلط، لأن arr **ثابتة** وما ينفعش تغيّر العنوان ده.

## الـ Const Pointer

في C++ فيه حاجة اسمها **const pointer**، ودي ليها معنيين:

### Pointer to const (مؤشر لقيمة ثابتة)

```c++
const int* ptr = &arr[0];
```

- هنا **القيمة اللي المؤشر بيشاور عليها مش ممكن تتغير** عن طريق المؤشر:

```c++
*ptr = 10; // ❌ غلط
```

- لكن المؤشر نفسه ممكن يشاور على عنصر تاني:

```c++
ptr = &arr[1]; // ✅ صح
```

- المعنى: "أنا مش هغير القيمة اللي المؤشر شايفها، لكن ممكن أغير المؤشر نفسه".
---

### 2️⃣ Const pointer (مؤشر ثابت)

```c++
int* const ptr = &arr[0];
```

- هنا **المؤشر نفسه ثابت**، يعني مش ممكن نخليه يشاور على عنوان تاني:

```c++
ptr = &arr[1]; // ❌ غلط
```

- لكن القيمة اللي المؤشر بيشاور عليها ممكن تتغير:
    

```c++
*ptr = 50; // ✅ صح
```

- المعنى: "المؤشر ثابت، لكن القيمة اللي شايفها ممكن تتغير".
    

---

### 3️⃣ Const pointer to const (مؤشر ثابت لقيمة ثابتة)

```c++
const int* const ptr = &arr[0];
```

- هنا **المؤشر ثابت** وما ينفعش نغيره يشاور على حاجة تانية،
    
- والقيمة اللي المؤشر شايفها **كمان مش ممكن نغيرها**.
    

---

## مثال كامل

```c++
int arr[3] = {10, 20, 30};

// مؤشر عادي
int* p1 = arr;
*p1 = 15;  // صح، غيرنا arr[0]
p1++;      // صح، دلوقتي p1 بيشاور على arr[1]

// مؤشر لقيمة ثابتة
const int* p2 = arr;
p2++;      // صح، ممكن نغير المؤشر
//*p2 = 25; // ❌ غلط، مش مسموح نغير القيمة

// مؤشر ثابت
int* const p3 = arr;
//p3++;     // ❌ غلط، مش مسموح نغير المؤشر
*p3 = 40;  // صح، ممكن نغير القيمة

// مؤشر ثابت لقيمة ثابتة
const int* const p4 = arr;
//p4++;     // ❌ غلط
//*p4 = 50; // ❌ غلط
```

## **الذاكرة الديناميكية (Dynamic Memory Allocation)**

لحد دلوقتي كنا بنشتغل على متغيرات **على الـ stack**:

```c++
int x = 10;
```

- هنا الميموري اتخزنت على الـ **stack**.
- لما الفانكشن خلصت، الـ compiler بيرجع يحرّر الميموري لوحده.
لكن ساعات بتحب تخصص ميموري **وقت التشغيل** حسب احتياجك، مش ثابت.  
ده اللي بنسميه **dynamic allocation**.
---

## استخدام **new**
ال `new` في C++ بتخصص مساحة في **الـ heap** (مش stack) وبترجع **pointer** للعنوان اللي اتخزن فيه المتغير.
### مثال لمتغير واحد

```c++
int* ptr = new int;  // خزن متغير int على الـ heap
*ptr = 100;          // استخدم القيمة
```

- `ptr` هنا **pointer** على المكان اللي اتخصص على الـ heap
    
- ممكن نغير القيمة اللي فيه: `*ptr = 200;`
### مثال لمصفوفة

```c++
int* arr = new int[5];  // مصفوفة من 5 أعداد على الـ heap
arr[0] = 10;
arr[1] = 20;
```

- دلوقتي الميموري دي **مش هتتحرر تلقائي** لما الفانكشن تخلص، لازم نحررها يدوي.
    

---

## استخدام **delete**

بعد ما تخلص استخدام الميموري اللي اتخصصت بـ `new` أو `new[]`، لازم **ترجعها للنظام** عشان ما يحصلش **memory leak**.

### لو استخدمت `new` → استخدم `delete`

```c++
delete ptr;   // حرّر مكان int واحد
ptr = nullptr; // أمان، عشان المؤشر مش يشاور على ميموري محذوفة
```

### لو استخدمت `new[]` → استخدم `delete[]`

```c++
delete[] arr; // حرّر مصفوفة
arr = nullptr;
```

---

## **ملاحظات مهمة**

1️⃣ **ممنوع تعمل delete لنفس المؤشر مرتين**

```c++
delete ptr;
delete ptr; // ❌ غلط، ممكن البرنامج يبوظ
```

2️⃣ بعد delete خلي المؤشر **nullptr**

```c++
delete ptr;
ptr = nullptr; // كده أي حد يحاول يستخدمه هيفشل بأمان
```

ال `new` بيخصّص على **heap**، مش stack

- الـ stack بيتحرر تلقائي عند انتهاء الفانكشن
    
- الـ heap محتاج تتحكم فيه بنفسك.
    

---

## مثال كامل

```c++
#include <iostream>
using namespace std;

int main() {
    // تخصيص int ديناميكي
    int* num = new int;
    *num = 42;
    cout << *num << endl; // 42
    delete num;
    num = nullptr;

    // تخصيص مصفوفة ديناميكية
    int* arr = new int[3];
    arr[0] = 10;
    arr[1] = 20;
    arr[2] = 30;
    for(int i=0; i<3; i++)
        cout << arr[i] << " "; // 10 20 30
    cout << endl;

    delete[] arr;
    arr = nullptr;

    return 0;
}
```
